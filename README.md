# MCP Server Deep Dive - Deployment

A comprehensive Model Context Protocol (MCP) server implementation for learning, testing, and deployment.

## Setup

### Prerequisites
- Python 3.10+
- `uv` package manager

### Installation

1. Create and activate the virtual environment:
```bash
source .venv/bin/activate
```

2. The dependencies are already installed via `uv pip install`.

## Running the Server

### Development Mode
```bash
uv run main.py
```

### Using MCP Inspector
```bash
mcp dev main.py
```

### Installing with Claude
```bash
mcp install main.py --name "Deep Dive Server"
```

## Server Features

### Tools
- `hello(name)` - Greet someone by name

### Prompts
- `greeting_prompt(topic)` - Generate a greeting prompt for any topic

### Resources
- `knowledge://welcome` - Server welcome resource with information

## Development

The server uses FastMCP 2.x with the following structure:
- `main.py` - Server implementation with tools, prompts, and resources
- `.venv/` - Python virtual environment
- `pyproject.toml` - Project configuration (auto-generated by uv)

## Architecture

This workspace is designed for:
- Learning MCP server development patterns
- Testing new features and implementations
- Preparing for production deployment
- Integration with Claude and other MCP clients
